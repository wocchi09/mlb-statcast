# MLB Data Lab

MLBの試合、順位、全選手の公式成績と2015年以降のStatcastを、スマホ対応のGitHub Pagesで分析する公開ダッシュボードです。

## 主な分析

- 試合：日付別スコア、イニングスコア、球場、先発、勝敗投手、セーブ
- 試合詳細：1試合ごとの全打席、全投球の球種・球速・配球図・カウント、打球速度・角度・飛距離、全打者・全投手ボックススコア
- 試合分析：独自推定勝利確率と勝負どころ、打球方向マップ、球速推移、投手・球種別Whiff／CSW／Zone／Chase、初球・2ストライク後の配球
- 試合前分析：予告先発のERA・FIP・K%・WHIP比較。試合開始後は配球分析へ自動切替
- 今日のStatcast：最新日の最速球、最速打球、最長打球、最多空振りを全試合から自動集計
- 深掘り分析：打者の球種別反応、カウント別配球、Hard-hit／Sweet Spot、独自打球品質・Stuff指数、リリース安定性、守備・走塁、天候・球場・球審
- 選手コンディション：直近7・15・30試合の公式成績を個人ページで比較
- シリーズ分析：チーム詳細で直近カードの勝敗・得失点を表示
- 出力：試合ごとの全投球データをCSVで保存
- 読みやすさ：試合詳細は「要点だけ／すべて表示」を切替可能。分析メニューから勝負どころ、配球、全打席、個人成績へ直接移動
- 順位：AL/NL全6地区、勝敗、勝率、ゲーム差、得失点差、連勝・連敗
- チーム詳細：全日程、直近10試合、打撃・投手力、累積得失点差、主要選手、40人枠の負傷者
- 全選手：公式打撃・投手シーズン成績、選手・球団・ポジション検索、球団絞り込み、規定到達、全列ソート、CSV出力、個人詳細ページ
- スプリット：対左・対右、ホーム・ビジター、月別の打撃・投手成績
- 選手比較：打者／投手を最大5人、MLB内パーセンタイルのレーダーと平均との差で比較
- お気に入り：選手・球団を端末内へ保存し、ホームから直接アクセス
- プレーオフ予測：勝敗と得失点を基に5,000回シミュレーションした進出確率と予測勝利数
- セイバー：wOBA、wRAA、ISO、BB%、K%、BABIP、FIP、FIP指数、K-BB%、Whiff%と打者・投手の分布図
- ホーム：最新試合、データ概況、直近7日の週間MVP候補、主要部門リーダー
- リーグ環境：球速、回転数、打球速度、Hard-hit、Barrel、Whiff、CSW
- 打者：AVG、OBP、SLG、HR、K、BB、EV、打球角度、xwOBA
- 投手：K%、BB%、球速、回転数、Whiff%、CSW%、xwOBA
- 球種：使用率、球速、回転、縦横変化、Whiff%
- 日次トレンド、選手比較、欠損率、指標ガイド、共有URL
- 詳細な任意期間分析はStreamlit版へ接続予定

## セイバー指標の計算

- wOBA：BB 0.69、HBP 0.72、1B 0.88、2B 1.247、3B 1.578、HR 2.031の公開固定ウェイトで算出
- wRAA：`(wOBA - リーグwOBA) / 1.25 × PA`
- FIP：`(13 × HR + 3 × (BB + HBP) - 2 × K) / IP + FIP定数`
- FIP定数：当年のリーグFIPがリーグERAと一致するよう、毎日の更新時に再計算
- FIP指数：`FIP / リーグFIP × 100`。100が平均で、低いほど優秀（球場補正なし）

wRC+とWARは、正確な球場補正、守備、走塁モデルが必要なため現時点では掲載していません。画面内の「指標ガイド」で数式、分母、注意点を確認できます。

## 自動更新

GitHub Actionsが毎日17:20（日本時間）に試合、順位、公式選手成績と当年Statcastを取得し、集計を差し替えます。当年の原データはGitHub Releaseの`data-current`へ保存し、過去全量の原本はGoogle Driveで保管します。すべて無料枠で動作します。

手動更新はActionsの`Daily Statcast update`から`Run workflow`を実行します。

プレーオフ確率は当サイト独自推定で、MLB公式予測や賭けの助言ではありません。左右・月別・ホーム／ビジター別成績は選手詳細の表示時にMLB公式Stats APIから取得します。
