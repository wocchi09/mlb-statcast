# MLB team logos

30 SVG logos downloaded on 2026-09-13 from MLB's asset host:
`https://www.mlbstatic.com/team-logos/{team_id}.svg`.

Filenames use MLB Stats API team IDs. These are current team marks, not historical season-specific logos. All marks belong to their respective owners; inclusion does not imply affiliation or endorsement.

The shared `teamBadge()` renderer uses these local files and falls back to a team abbreviation if an image cannot load.
